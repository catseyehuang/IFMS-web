GitHub Pages 外網部署指引

如欲讓合夥人在外網隨時使用手機開啟本系統，請將專案中的 /frontend 資料夾推送到 GitHub 並開啟 GitHub Pages：

  1. 建立一個 GitHub Repository (如 IFMS-web) 並上傳前端檔案。
  2. 於 GitHub 設定中啟動 GitHub Pages 發佈。
  3. 複製發佈的網址 (如 https://username.github.io/IFMS-web/)。
  4. 前往 Google Cloud Console 將該網址加入「已授權的 JavaScript 來源」。
